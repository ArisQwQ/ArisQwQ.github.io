# NOIP 2021 T1 題解

## 題意

給定兩個數字 $a, b$ ，和自己決定的非負整數 $x$ ，找到一个 $x$ 使得 $\text{lcm}(a+x,b+x)$ 最小化。

## 解法

答案中 $ansa=a+x, ansb=b+x$ 一定可以寫成 $\text{lcm}=\gcd(ansa,ansb)\times\frac{ansa}{\gcd}\times \frac{ansb}{\gcd}$ 。  
設 $x=\frac{ansa}{\gcd}, y=\frac{ansb}{\gcd}, m=\gcd$ ，  
則 $ansa=mx, ansb=my$ ， $my-mx=m(y-x)=b-a$ ， $\text{lcm}=mxy$  

發現， $m$ 是 $ b-a $ 的因數，枚舉 $m$ ，  
$\text{令}\ t=y-x = \frac{b-a}{m},\ y=t+x$  
$ansa=a+x=mx>a, \text{同理}\ my=mx+mt>b$ 。 $\text{lcm}=mxy=mx(t+x)$  

解不等式  
$ \begin{cases}mx\ge a,\\mx+mt\ge b\end{cases}$
解得 $x\geq \max(\frac m a, \frac{b-mt} m)$ ，這个算式保證 $x,y > 0$  
$\text{lcm}=mxy=mx(t+x)$   
由於 $m>0 ,\ y>0 ,\ x>0$ ， $m$ 固定  
要使 $\text{lcm}$ 最小，要 $xy$ 最小，要 $x=\lceil \max(\frac m a, \frac{b-mt} m)\rceil$ 

初始化 $ans=\text{lcm}(a,b)$，每次枚舉 $m$ 做 $ans=\min(ans,mx(x+t)) \ \ \  (x=\lceil \max(\frac m a, \frac{b-mt} m)\rceil )$  即可

# 代碼

```cpp
#include<stdio.h>
#include<algorithm>
#define lcm(a,b) ((a)*(b)/std::__gcd(a,b))
#define max(a,b) std::max(a,b)
#define min(a,b) std::min(a,b)
typedef long long ll;
void solve(){
	ll a,b;
	scanf("%lld%lld",&a,&b);
	if(a>b)std::swap(a,b);
	ll cha=b-a;
	ll ans=lcm(a,b);
	for(ll i=1;i*i<=cha;i++){
		if(cha%i!=0)continue;
		do{
			ll m=i;
			ll t=cha/m;
			ll minx=max((a+m-1)/m,(b-m*t+m-1)/m);
			ans=min(ans,1ll*m*minx*(minx+t));
		}while(0);
		do{
			ll m=cha/i;
			ll t=cha/m;
			ll minx=max((a+m-1)/m,(b-m*t+m-1)/m);
			ans=min(ans,1ll*m*minx*(minx+t));
		}while(0);
	}
	printf("%lld\n",ans);
}
signed main(){
	int c,t;
	scanf("%d%d",&c,&t);
	while(t--)solve();
	return 0;
}
```
